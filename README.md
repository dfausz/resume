# 💼 Resume  
### _A Clean, Interactive Portfolio Site_

A simple yet polished portfolio site built with **Angular** and **Angular Material**, designed to showcase professional experience, projects, and contact information with a clean UI and subtle animations.  

The site emphasizes clarity, interactivity, and visual flow — presenting a developer’s identity in a lightweight, elegant package.

---

## 🧰 Tech Stack
| Layer | Tools / Frameworks |
|--------|---------------------|
| Framework | [Angular](https://angular.io/) |
| UI System | [Angular Material](https://material.angular.io/) |
| Animations | Angular’s built-in Animation API |
| Design | Custom theme + responsive layout |
| Hosting | GitHub Pages / lightweight static deployment |

---

## ✨ Features
- ⚙️ **Angular + Angular Material Foundation** – Provides responsive design and layout scaffolding  
- ✨ **Animated Intro** – Cycles through phrases (“I am a ___ developer”) before landing on “software”  
- 🎛️ **Interactive Navigation Menu** – Animated top navigation bar that expands on interaction  
- 🌈 **Morphing Background Blobs** – Animated, slow-moving shapes in the Skills section for visual interest  
- 🔗 **Direct Contact Links** – One-click access to socials, email, and professional profiles  
- 💡 **Minimal, Fast, and Responsive** – Built for clarity and performance on any screen

## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/dfausz/resume.git
cd resume
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
ng serve
```
Then open your browser at [http://localhost:4200](http://localhost:4200).

### 4. Build for production
```bash
ng build --prod
```
The output will be generated in the `dist/` folder.
